# 전생 거울 (pstlf.co.kr)

재미로 보는 전생·인연·타로 사이트.

- `/` 첫 화면 (테스트 목록, 읽을거리)
- `/past-life/` 전생 체험
- `/bond/` 전생의 인연 궁합
- `/tarot/` 오늘의 타로 한 장
- `/tarot/2027/` 2027년 신년 타로 (카드 세 장: 상반기, 하반기, 올해의 열쇠)
- `/tarot/cards/` 메이저 아르카나 22장 의미
- `/read/` 읽을거리
- `/about/` 소개, 문의
- `/shop/` 숏폼 영상 속 상품 모음 (쿠팡 파트너스 링크, 번호로 찾기). 검색·사이트맵·메뉴에서 빠져 있어요.
- `/assets/` 공통 스타일(site.css)과 기능(site.js: 공유 창, 생년월일 입력)

## 페이지 다시 만들기

사이트를 고친 뒤에는 항상 아래 두 줄을 실행하고, 마지막 줄이 `문제 0건`일 때만 올려요.

```
python3 _build/build.py
python3 _build/qa.py
```

`qa.py` 는 모든 페이지를 휴대폰(320px, 390px)과 PC 크기로 열어 오류, 깨진 링크, 화면 넘침을 보고,
네 테스트의 입력·결과·공유 링크·공유 창, 타로 하루 한 장과 카드별 누를 수 있는 폭까지 확인해요.
공유 창은 버튼마다(카카오톡, 메시지, X, 스레드, 페이스북, 복사하기, 더보기) 담기는 글과 주소, 카카오톡 카드 그림과 버튼 주소,
친구가 그 링크를 열었을 때 같은 결과가 나오는지, 친구 화면 맨 위와 아래에 '나도 해 보기' 버튼이 제대로 뜨고 눌리는지도 봐요. 모든 페이지의 공유 그림 파일과 크기, 공유 주소도 함께 확인해요.
(Python Playwright, Chromium 필요)

`build.py` 를 실행하면
테스트 아래 설명글, 카드 의미, 읽을거리, 소개, 개인정보처리방침, 404, sitemap 이 다시 만들어져요.
신년 타로의 카드별 2027년 풀이는 `_build/content_newyear.py` 에 있고, build.py 가 신년 타로 페이지와 카드 의미 페이지에 채워 넣어요.
(Node.js 필요. `_build` 폴더는 사이트에 올라가지 않아요.)

## 상품 모음 (/shop/)

상품은 `shop/items.txt` 한 파일만 고치면 돼요. 한 줄에 상품 하나씩, 칸은 `|` 로 나눠요.

```
번호 | 상품명 | 쿠팡 파트너스 링크 | 한 줄 소개 | 분야 | 상품 사진 주소
12 | 무선 미니 청소기 | https://link.coupang.com/a/xxxxxx | 차 안 먼지까지 한 번에 | 청소
```

- 영상에서는 "프로필 링크에서 12번" 처럼 번호로 안내해요. `https://pstlf.co.kr/shop/?n=12` 로 열면 그 상품만 바로 나와요.
- 한 줄 소개, 분야, 사진 주소는 비워 둬도 돼요. 같은 번호는 한 번만 써요.
- 페이지 맨 위의 쿠팡 파트너스 대가성 문구는 지우면 안 돼요.
- `items.txt` 만 고쳤을 때는 build.py 를 다시 돌리지 않아도 바로 반영돼요. `qa.py` 는 줄 형식과 겹치는 번호도 확인해요.
- 전생 거울과 분위기를 다르게(밝은 파스텔) 하려고 공통 틀 대신 따로 만든 틀을 써요. 맨 위 전생 거울 이름과 메뉴도 없어요.
- 링크를 붙였을 때 보이는 그림 `share-shop.png` 는 `python3 _build/make_share_shop.py` 로 만들어요.

## 신년 타로 공유 이미지

`share-2027.png` 는 `python3 _build/make_share_newyear.py` 로 만들었어요. 문구를 바꿀 때만 다시 실행하면 돼요.

## 설정

- 네이버 서치어드바이저 소유확인: 첫 화면(`index.html`) `<head>` 의 `naver-site-verification` 태그. 지우면 소유확인이 풀려요.

- 카카오톡 공유: `assets/site.js` 의 `kakaoKey` 에 카카오 JavaScript 키를 넣어요.
- 광고: 쿠팡 배너는 각 테스트의 `쿠팡 파트너스 배너 코드` 주석 사이, 애드센스는 `<head>` 안에 있어요.
